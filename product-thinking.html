01 / FROM RESEARCH TO POSITIONING

这不是凭空想象，
是被形态一步步推出来的。

先看市场，再看骰子的身体限制，最后才得出“实体数字生命”这个方向。每一步都在排除不适合它的产品定义。

A

调研发现

儿童产品大致走向两端

垂直功能为特定年龄或群体解决一个明确问题。
物理玩法依靠抓握、建构、运动和想象适配儿童。

功能越聚焦，品类越窄；玩法越开放，关系越长。

→
B

形态判断

六面体不是垂直功能机器

它的优势不在于塞进一个成人工具，而在于孩子天然会对它做什么：拿、翻、滚、堆、传、带走。

拿翻滚堆带走

它先是一个被身体理解的体块，再是一个电子产品。

→
C

核心结论

让体块成为一个“谁”

把已有硬件的感知与表达，放进一个有状态、有偏好、有记忆的二进制生命体里。

“孩子做的每个动作，都可以成为它理解世界的方式。”

不是让骰子功能更多，而是让每次玩法都多一层关系。

02 / THE UNCHANGED CORE

内核不换皮，
它才像同一个生命。

核心不靠主题音效成立，而靠一条持续的因果链成立：咔卟表现需要，孩子尝试照料，它做出回应并逐步恢复，之后仍记得这段经历。

照料
关系我看见需要，也看见回应

2—4 岁 · 感官探索

触感与安全

高对比颜色、不同纹理和声音刺激；外壳一体、易清洁、少零件。通过 IMU 可识别范围内的摇晃、翻转、静置，咔卟用简单声音和震动回应。

4—7 岁 · 动作探索

操作与即时因果

增加推动、滚动、开合、简单拼接或变形；孩子一操作，咔卟就用音调、震动或可实现的翻滚反馈。机关状态若要被识别，需加开关。

7—12 岁 · 身份与故事

个性化与装备感

可装扮、组合和收集，满足潮流、社交认同与科技装备想象；例如机甲外壳。通过 NFC 情境配件照料咔卟，在故事中获得成长、知识和成就感。

所有年龄 · 安全底线

材质与结构

耐摔、好抓握、便于清洁；小零件、磁铁、夹手缝隙和电池仓按年龄分别验证。

统一原则外壳改变触感、操作和叙事入口；照料关系与生命记忆仍属于同一个咔卟。
年龄不是三套产品内核2—4 / 4—7 / 7—12 是外壳与配件的设计侧重点；最终年龄标注仍需依据尺寸、可拆部件、材料和安全测试确定。

04 / CARE & EMPATHY

照料不是打卡，
是看见需要与回应。

孩子观察咔卟的状态，尝试带来合适的照料；咔卟给出即时回应，并在一段时间里逐渐恢复。App 帮助孩子看懂发生了什么，但不代替实体互动。

01 / NOTICE

咔卟现在不太舒服

生命状态变弱时，发出音调逐渐下滑、尾音变短的声音；回应变少、震动变轻。它表达需要，但不持续催促孩子。

孩子看到它状态不太好，可能需要照料。
02 / OFFER CARE

孩子带来露水

孩子把露水 NFC 物件靠近骰子的指定感应区。NFC 识别的是“露水配件到了”，不是孩子的情绪或照料意图。

关键设计将配件靠近感应区，成为清楚、可重复的实体动作。
03 / RESPOND

它让孩子知道“收到了”

咔卟立即发出对应的短音与震动。比如露水是舒缓的节奏；阳光可以是上扬音调；土壤可以是稳定、低频的震动。现有蜂鸣器更适合改变音高、节奏和停顿，音强变化范围有限。

硬件表达蜂鸣器音调 / 节奏 + ERM 大致震动强弱；不依赖灯光。
04 / RECOVER

照料有效，但不是瞬间满格

状态从“收到照料”进入“正在恢复”，再逐渐变得稳定、有活力。骰子的反馈也随状态变化，而不是碰一下就立即变强壮。

避免不因孩子没玩而惩罚、退化或死亡。
05 / UNDERSTAND

App 帮孩子看懂变化

App 按日记录露水被识别和恢复过程，配一条与故事相关的简短知识。重点是理解“水分帮助它恢复”，不是做题或领成长积分。

同理心路径注意信号 → 理解需要 → 尝试回应 → 观察结果。

05 / HARDWARE REALITY

哪些能沿用，
哪些需要补齐。

把生命表达落到现有硬件边界上：先用声音、震动、IMU 和 NFC 做一个可信的闭环，不把未验证的动作能力写成既有功能。

模块当前基础照料玩法中的作用状态
IMU 加速度计已有识别翻转、滚动、摇晃和静置；不识别意图沿用并验证
ERM 震动马达已有区分短震、长震、节奏与大致强弱；主动抖动/摇摆需调校沿用并验证
蜂鸣器 / PWM已有下滑尾音、音高、节奏和“电报式”短音；音强变化有限沿用
BLE + App已有选择情境、按日同步配件事件、展示状态和照料记录沿用并补软件
NFC 读卡器 + 天线当前骰子需新增识别露水、阳光、土壤等带标签的实体配件必须新增
本地状态 / 事件存储需确认主控余量离线时记住状态与事件，连接 App 后再同步必须确认
扬声器 / 麦克风 / LED当前闭环不需要丰富语音或环境感知才需要；本方案不依赖灯光暂不新增
关键限制ERM 可以带来震动、抖动和摇摆感；骰子主动翻滚的幅度、方向和可重复性需要结构样机验证。“真正跳起”或精确控制移动，需要额外机械机构，不应当作现有能力。

06 / PRODUCT THESIS

同理心不是一条课程，
而是照料里发生的体验。

咔卟需要做到
  • 状态信号稳定，孩子能察觉
  • 配件有清楚的照料含义
  • 照料后骰子立刻回应
  • 状态变化逐步发生且可理解
咔卟不应该
  • 因孩子没玩而责备或惩罚
  • 把 NFC 碰触伪装成理解意图
  • 只用积分代替生命状态变化
  • 为了讲科普而打断游戏
首发验证标准孩子能察觉需要、主动尝试照料、看懂回应，并愿意回来继续关心它。

07 / LATEST ITERATION

从“照料它”，
扩展到“和它一起生活”。

最新判断：照料是咔卟的一种关系场景，不是唯一玩法。更大的产品概念是陪伴；孩子可以照料它、和它做音乐、一起探索或玩游戏。不同情境共享同一个生命内核、感知方式和记忆。

SCENE PACK / MODULAR SOUND STORY

把咔卟和配件，
编排成一段声音故事。

图中模块化角色、底座和配件只是编排方式的示意：咔卟和有声配件可以分别代表故事角色、音节、节奏或演奏风格。孩子通过拼接、排布和改变顺序，让不同配件发出声音，并组合成不同的音节、节奏或音乐。

1选择有声配件2拼接或排布3组合发声4换顺序再演绎
有声配件设定配件本身可以发声，但它就不再是单纯的无源 NFC 标签：每个有声配件需要蜂鸣器或微型扬声器、简单主控和安全供电，NFC 或底座触点用于身份识别、位置确认与演奏触发。不同配件负责不同音节或节奏，排列完成后由咔卟或底座协调播放。低龄版本应采用封闭式充电结构或由底座供电，避免儿童可接触的纽扣电池。

  2. 实体配件NFC 代表什么角色或物件

  6. 家长延伸可选知识点或共同话题

生命状态是共用底层；每个情境有自己的进展和记忆。不要把音乐也做成喂养，不要让所有主题都只是在刷成长值。

WHO PAYS / WHY

孩子想玩，
家长觉得值得。

购买动力目前是产品假设，后续要用家长访谈和孩子试玩验证。家长通常不会为“二进制生命体”这个内部概念买单。

孩子的吸引力它会回应，而且能动手改变它

摸、拼、摆、滚、发声；不是只能看屏幕或听讲解的玩具。

家长的价值理由同一件玩具，随年龄和兴趣继续长出玩法

感官与动作探索、动手创造、故事陪伴、同理心练习和科普内容，可以成为不同阶段的价值。

持续购买理由换场景配件，不必换掉熟悉的伙伴

外壳与场景包带来新玩法；孩子持续认识的是同一个咔卟，而不是一批互不相关的小玩具。

购买底线安全、耐用、易清洁，App 不霸占玩耍

尤其低龄外壳要适龄安全；App 用于设定、理解与记录，实体互动要能独立成立。

购买逻辑孩子被“会回应、能参与、能组合”吸引；家长为动手体验、开放玩法、适龄价值和可持续扩展付费。

08 / BASE SKU · NO EXTRA KIT

没有额外套件，
骰子本身就能成立。

每个基础 SKU 默认带一个固定、适龄的保护外壳，不依赖可拆配件。孩子只用一颗或多颗咔卟，通过掷、滚、翻、摇、传递与 App 场景，就能完成一套儿童玩法。

一个基础 SKU 六面玩法内容+场景规则+生命反应包+App 内容 共用同一套硬件内核；固定外壳、六面图案和软件内容定义 SKU 差异。
FUNCTION / 玩法层

告诉孩子这一轮做什么

骰子稳定后读取顶面，App 或面上图案给出清楚任务：跳跃、旋转、讲故事、模仿节奏、完成生活小任务。

同时发生
LIFE / 生命层

决定咔卟如何参与

根据本轮内容、动作强度、当前精力、性格和近期经历，选择声音、震动、抖动或休息反应，并更新下一次状态。

SKU EXAMPLE / 身体运动骰子

掷到什么运动，孩子就做什么；
咔卟用不同生命反应陪着完成。

跳跃连续跳 5 次

快速上扬短音、连续短震，像在一起使劲。

旋转原地转一圈

旋转式音调后下滑，轻微抖动，像有点晕。

平衡单脚站 10 秒

安静下来，用轻微节拍陪伴；结束后突然回应。

伸展双手向上舒展

长音逐渐升高，震动从弱到稳，像一起伸懒腰。

动物移动模仿青蛙或小熊

发出对应节奏的咔卟语，邀请孩子模仿。

呼吸休息慢慢呼吸 3 次

缓慢规律的震动和低音，生命状态逐渐平静。

同一面，也不是固定音效运动类型 + 动作强度 + 当前精力 + 性格 + 最近是否连续运动 → 本次生命反应
单颗咔卟 / 基础儿童场景

一个固定外壳，也能对应不同明确 SKU。

01

身体运动

跳、转、平衡、伸展、模仿动物；生命反应表现兴奋、紧张、眩晕、疲惫与恢复。

02

节奏与音乐

咔卟发出声音和震动节奏，孩子拍手、摇动或敲击模仿，再由 App 增加难度。

03

故事骰子

六面对应人物、地点、事件或情绪；每次翻面推进故事，咔卟对剧情产生反应。

04

生活习惯

洗手、收纳、刷牙、睡前等生活小仪式；咔卟负责随机选择、陪同节奏和完成回应。

05

寻找与追逐

咔卟间隔发声、震动或随机抖动，孩子在安全空间寻找、追踪或把它送回指定位置。

06

亲子轮流

随机决定谁先开始、抽取聊天问题或合作任务，让咔卟成为亲子互动中的第三个角色。

MULTI-CUBE / 多颗组合

多颗不是重复，
而是把玩法拆成多个维度。

每颗咔卟负责一个规则，组合后生成更多变化；同时它们可以用不同性格回应，形成一群陪孩子玩的二进制小生命。

第一颗决定运动或故事事件
+
第二颗决定次数、时长或速度
+
第三颗决定角色、情绪或完成方式
=
组合任务形成动作接力、群体故事、节奏乐团或团队挑战
骰子可以知道

自己被掷、摇、翻、滚或重新静置；哪一面朝上；动作大致强弱；App 下发了什么场景规则。

骰子不能直接知道

孩子是否真的完成标准跳跃、刷干净牙、吃了一口饭，或现在是什么情绪。完成可用计时结束、摇一下确认或 App 点击确认。

基础产品原则先保证没有任何额外套件时，玩法本身就好玩；二进制生命反应负责让同一套规则更有趣、更有关系感，也更值得反复玩。
